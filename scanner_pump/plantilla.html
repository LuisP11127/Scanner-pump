Medida

Guardar el seguimiento en GitHub

  1. Abre crear una clave (fine-grained token) en GitHub.
  2. Ponle un nombre (por ejemplo, Scanner-pump). En Repository access elige Only select repositories y tu repositorio.
  3. En Permissions → Repository permissions → Contents elige Read and write.
  4. Pulsa Generate token, copia la clave y pégala aquí.

La clave se guarda solo en este navegador y solo se envía a GitHub. Cada día de seguimiento queda como un archivo en datos/seguimiento/ del repositorio.

Datos: API pública de Binance (spot: data-api.binance.vision · futuros: www.binance.com). Gráficos: TradingView Lightweight Charts. No es una recomendación de inversión.
